# Studies

A study is a sandbox for building research tools around one question. It sits beside the
Logic Portal and draws on it, reading the same texts and opening every passage in the
portal, without changing the portal. Features built for one question stay in its
study. If one would help everyone, it goes to the portal as a pull request of its own.

Each study has its own folder here, with an `index.html`, a `README.md` for a human, a
`CLAUDE.md` of rules for sessions working in it, and a `journal.md` of what each feature
showed. Like everything under `logic-portal/`, a change to a study needs nobody's
approval.
