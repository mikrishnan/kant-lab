The seminar’s board

One board, the same for everyone in the Kant Lab. Anyone with the password can open it and change it. The password is told in the seminar.

: the study’s own starting board, read only.

Setting up the shared board

Done once, by whoever looks after the board, and again when its token expires or the password changes.

  1. On GitHub, a private repository . It can be empty.
  2. A fine-grained token for that repository alone: Repository access → Only select repositories → it; Permissions → Contents: Read and write.
  3. Paste the token and choose the password below. The token is checked with GitHub, the starting board is put in the repository if it is empty, and you get back board-shared.js with the token locked by the password. The password is not kept anywhere.
