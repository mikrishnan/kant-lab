# The class screen

A class session on the room's screen: its passages in large type, one after another, with the
English beneath them when you want it. Open it from the portal's **Session** panel (**Screen ↗**)
or the session page (**Class screen ↗**). It opens in a window of its own, which you can drag onto
the room's screen and make full screen, while the portal stays on your laptop.

**What it shows.** By default, the session you are preparing in this browser: the one the Session
panel collects. It follows that session as you work. A passage, note or cluster you add in the
portal appears on the screen, and the screen keeps its place. From the menu at the top left you can
show a session saved for the class instead, or open a file saved with **Save to file**. A saved
session also opens directly at `class-screen/?session=<name>`, and its page in the portal has an
**On the class screen** link.

**Clusters** show as a heading with their passages beneath it, numbered 3.1, 3.2 and so on. A
cluster always shows as it is now. In a saved session, a passage added to the cluster after that
class says so, and so does a passage that has been taken out since.

**Moving through it**

| Key | |
| --- | --- |
| ↓, →, Space, Page Down | on: through a long passage a screen at a time, then to the next item |
| ↑, ←, Shift-Space, Page Up | back |
| Home, End | the first item, the last |
| E | English: none, then each of the translation styles in turn |
| N | your notes on passages, shown or hidden |
| C | the passage in context: the portal beside it, opened at that passage |
| F | full screen. The bar fades after a moment and comes back when the mouse moves |
| + and − | larger or smaller type |

The menu in the middle of the bar goes straight to any item. Clicking an item makes it the one in
hand.

**What it says about the texts.** The English is a machine translation following one published
translator's method, and the screen says so above each one, as the portal does. A passage from a
text that is OCR carries the text's measured share of words right. A Reflexion's dating is Adickes'
phase, with the portal's years beside it.

**How it works.** The screen loads the portal itself, hidden, and reads the passages and the English
from it, so it shows exactly what the portal shows. It reads the class sessions as the portal keeps
them, and changes neither. It therefore has to be opened from the same site as the portal, on GitHub
Pages or a local server, not as a file. The first opening takes as long as the portal does to load.
