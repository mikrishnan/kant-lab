# Teaching tools

Small tools made for teaching with the Logic Portal, a new one most weeks. Each sits beside
the portal and draws on it, reading the same texts and the same handouts, without changing
it, so the portal stays as everyone knows it. They are listed at
[teaching/index.html](index.html).

Each tool has its own folder here, with an `index.html` and a `README.md` for a human. Like
everything under `logic-portal/`, a change here needs nobody's approval.

| Tool | Begun | What it is for |
| --- | --- | --- |
| [class-screen/](class-screen/) | 8 November 2026 | A handout on the room's screen, passage by passage |

To add one, ask Claude for it in plain words, as a teaching tool. It goes in a folder of its
own here, with an entry in [teaching.js](teaching.js), the list the index page shows, and a
row in the table above. A tool that is used every week can move into the portal itself, by a
pull request of its own. One that is no longer used is retired: its page becomes a short
notice, and its entry says so.
