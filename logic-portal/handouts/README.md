# Class handouts

Each `.json` file here is a handout published for students from the Logic Portal's
handout tray (**Publish for students** on the Handouts page). The portal shows one at
`../?handout=<file name without .json>`, and lists them all under **Read**, as class
handouts.

A file holds the handout's title, its headings and notes as written, and each passage
by its portal address (`textKey:id`), with its label and note if it has them. An
excerpt also keeps its words. A passage joined from several also lists every part's address
and citation (`refs`, `cites`); its `ref` is the first part's. So students read every passage
live, from the portal's own texts.

To take a handout down, delete its file. To change one, publish it again from the tray:
the new file replaces the old.
