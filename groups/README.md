# Working groups

Each folder here is one working group's playground: its spec, its tool, and anything
else the group needs while the tool is a work in progress. A group's members approve
each other's changes to their folder; nothing outside it is theirs to change.

New groups start from [_template/](_template/), by way of a **New working group**
issue. The folder is created for you. How groups work — specs, pull requests, review,
promotion to a finished tool — is in the root README's
[Working groups](../README.md#working-groups) section.
