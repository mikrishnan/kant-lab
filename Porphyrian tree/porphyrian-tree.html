Ars combinatoria

Enter a list of differentiae. On Populate, a fresh binary tree is built from the summum genus, splitting on each differentia in turn, so the bottom level manifests every combinatorial infima species (2ⁿ in all).

Leibniz Mode ▾
Characteristica singularis

Like Wolff Mode, but each differentia is used only once. Each node consumes the next differentia to split into present / non-present; the differentia then belongs to that branch alone and never recurs elsewhere. With n differentiae the tree has n splits and n+1 infima species.
