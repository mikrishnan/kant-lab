# Aidan

Aidan's own project folder.

- [judgment-finder.html](judgment-finder.html) — the Logik Blomberg, Busolt and Wiener
  transcripts in tabs, with a panel that finds the judgments the lectures use as examples
  and labels each on Kant's four heads. Reads `../../data/logik-*-24.js`.
- [judgment-forms.md](judgment-forms.md) — what counts as each form, rule by numbered
  rule, with the lectures' own criterion for quality quoted from AA 24:930. The
  classifier in the app implements it; read this before changing the rules.
