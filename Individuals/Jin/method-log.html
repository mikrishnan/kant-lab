Kant Lab Method Log

Every idea, across sessions

Threads: one idea followed from session to session

A thread is a tag you give ideas (in ✎, "Threads"), such as nihil negativum or concept search. Here each thread is listed with every idea that carries it, in the order of the sessions, so you can see how a question, or a way of working on it, developed.

Import and export

To Google Sheets

Two sheets: one row per session, and one row per idea (with its session's date and title). Click a cell in the sheet and paste.

Back up

The whole log as one file, which Import reads back here or in another browser. Do this regularly: the log lives only in this browser.

Import

A backup file (this version or the earlier one), or the ideas sheet pasted from Google Sheets with its header row. Ideas are put in the session with the same date and title, which is made if it does not exist; nothing already in the log is changed, and an idea already there is not added twice.

Example
