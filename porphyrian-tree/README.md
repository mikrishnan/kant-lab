# Porphyrian Tree (retired)

The Arbor Porphyriana rule configurator, a tool for building genus–species trees under
rules of division the reader chooses, was one of the seminar's early experiments. It was
retired on 4 November 2026, with the Porphyrian trees participants had built in
`Individuals/`.

[porphyrian-tree.html](porphyrian-tree.html) now says so. The tool as it last stood, with
its notes for Claude, is at commit
[`9d47366`](https://github.com/mikrishnan/kant-lab/tree/9d473662a1a2a947232aed780ffbd180e9f233c0/porphyrian-tree);
[open it as it was](https://raw.githack.com/mikrishnan/kant-lab/9d473662a1a2a947232aed780ffbd180e9f233c0/porphyrian-tree/porphyrian-tree.html).
